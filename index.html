Google Sheet Database & GitHub Pages Setup

1 Google Sheet Connection Settings

Important for Live Sync: In Google Sheets, click Share → General access → Anyone with the link (Viewer) or File → Share → Publish to web so GitHub Pages can read the live database directly without a backend server.

2 How to Host Free on GitHub Pages (2 Minutes)

  1. Create a new repository on github.com/new (e.g., board-dashboard).
  2. Upload this single file renamed as index.html into the repository root.
  3. Go to Repository Settings → Pages, under Source choose Deploy from a branch, select main / / (root), and click Save.
  4. Your live Board Meeting URL (https://<username>.github.io/board-dashboard/) will automatically pull fresh numbers every time you update your Google Sheet!
